DIRECTION A — DENSE POWER-CONSOLE LAYOUT (density-first, one screen, minimal scrolling)

Restructure this human-review page into a dense, keyboard-friendly operator console. Optimize for "clear many products per hour", not for reading prose. Keep the exact same indigo/emerald palette, the same Chinese labels, the same fields, the same buttons and the same functionality — change only layout, density and hierarchy.

Layout changes:
- Give the app a fixed full-height shell: keep the sticky topbar, and add a persistent LEFT SIDEBAR (about 220px) that lists the page's task groups as jump links with a small status dot each — 文案与标题 · 价格与库存 · 视频与详情页 · 颜色变体 · 图片 · 发布前检查.
